# EBGeo: do terreno à decisão

Apresentação do EBGeo, a base de geoinformação do Cenário Operacional Comum.

Abra em https://dsgoficial.github.io/ebgeo-apresentacao/

- Seta para a direita, espaço ou clique: avança um passo.
- Seta para a esquerda: volta.
- F: tela cheia. Home: recomeça.

A página funciona sem rede depois de baixada: basta abrir o `index.html` com a pasta `midia/` ao lado.
Todas as telas são imagem real do EBGeo.
